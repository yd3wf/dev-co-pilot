# AI 代码维护台账

记录 AI 生成代码的维护状态。复制本表并按需填写。

| 字段 | 内容 |
|---|---|
| 模块 | 代码属于哪个业务模块 |
| 负责人 | 谁负责后续维护和决策 |
| 业务规则 | 代码背后的关键业务约束 |
| 外部依赖 | 数据库、缓存、消息、第三方接口 |
| 测试状态 | 已覆盖 / 未覆盖 / 待补充 |
| 风险等级 | 普通 / 重要 / 高风险 |
| 技术债 | 已知重复、复杂、临时或待重构部分 |
| 最近验证 | 最近一次编译、测试和线上验证时间 |

## 使用示例

| 模块 | 负责人 | 业务规则 | 外部依赖 | 测试状态 | 风险等级 | 技术债 | 最近验证 |
|---|---|---|---|---|---|---|---|
| 订单 | 张三 | 支付成功后 24h 内可退款 | MySQL、Redis、支付网关 | 已覆盖 | 高风险 | 状态机分支复杂，待抽取 | 2026-08-01 |
